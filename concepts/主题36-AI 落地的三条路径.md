# 主题36：AI 落地的三条路径（通用版）

## Compiled Truth

`concepts/` 下 35 个概念压成三条路径，每条都是一个五步闭环，可以脱离任何具体行业单独讲。

**三条路径的分工**：一个人怎么开始用（找 / 选 / 用 / 留 / 再）、一个团队怎么起来（找 / 给 / 赢 / 传 / 再）、怎么从「用工具」到「有搭档」（装 / 喂 / 问 / 纠 / 长）。前两条讲扩散，第三条讲深度。

**共同的形状**：五步串成一条链，链的末端绕回起点，成一圈。走一圈之后位置变了，所以第二圈更快。这是三条路径共用的结构，也是「闭环」这两个字的兑现。

**共同的卡点**：三条路径都卡在第三到第四步之间。个人卡在选了工具却只解决一件事、团队卡在给了资源却没人跑出结果、深度卡在问了很多次却从不纠错。共同原因是同一条，启动很容易，坚持到出结果很难。

**共同的反常识**：起点都不是工具。个人从那件事开始，团队从那个人开始，深度从那堆自己的材料开始。从工具出发，永远找不到该用在哪儿。

## 关键要点

- **三条路径共用一个形状**——五步链 + 末端回流，转一圈位置就变了
- **起点都不是工具**——从那件事、那个人、那堆材料开始
- **三条都卡在第三到第四步之间**——启动容易，出结果难
- **每条五字口诀**——找一个点/选一个工具/只解决这一件/把做法留下/再找下一个
- **视觉语言**——五个字母级汉字做节点，一条曲线串起来，虚线回环；文字砍到每格 30 字以内

## 📌 每日对话（2026-11-10）

**碰撞：**昨晚 22:07 提需求 → 22:19 判 v1「都是文字、没有流转」→ 22:22 三张 v2 换完。v1 其实已经走到第 4 步（图出来了、做法也留下了），却被整体推翻退回第 2 步重做——不是卡在 3→4 的「坚持不下来」，而是卡在 4→5 的「做出来了，却不敢拿出去」。三条路径「共同卡点在第 3 到第 4 步之间」这个结论要修正：真正的断点在交付验收，不在执行耐力。

**纵深：**1932 年劳伦斯回旋加速器——粒子不是被一条直线一次拉到底，是反复穿过同一条缝，每穿一次被电场推一把，轨道越转越大、也越转越快；本事不在直线有多长，在同一条缝被穿过多少次。路径末端的「再」即此：第二圈不是新流程，是同一个起点第二次经过。边界：接近光速后回旋加速器失效，必须换同步加速器——同一条闭环不能无限转，体量一大要换结构，不是再加一圈。

**落地：**三张图对外讲时，最危险的场面是对方第一句问「那我该用哪个工具」——一被问就退回起点，而三条路径共同的起点恰恰不是工具。开场别先放图，先问「这周最耗你时间的一件事是什么」，让他的答案自己落进第一个格子。验收标准也不是好不好看，是别人能不能在图上找到自己现在站的位置。
