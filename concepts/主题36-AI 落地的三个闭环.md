# 主题36：AI 落地的三个闭环（方法论蓝图）

## Compiled Truth

`concepts/` 下 35 个概念散着看是 35 个点，压到底只有三条线，三条线共用同一个发动机。

**三条线**是三个尺度上的同一件事。人的尺度（一个人怎么长出 AI 能力）、组织的尺度（一个组织怎么走到 AI Native）、交易的尺度（一次 AI 单子怎么赢下来又变成下一个客户）。每一层都是一个自增强的环，环的产出是下一层的输入。

**同一个发动机**是 Context not Control。给个人喂上下文，给组织设计环境，给 Agent 造缰绳，是同一个动作。三层同构的判据是「约束结果，不约束路径」——Control 约束行为序列，Context 提供信息域，Environment 约定出口标准。

主线的选择是刻意的。对外讲时走人的线开场，因为这是唯一能被听者直接代入的尺度，组织与业务是放大与兑现。

**三个环各自的最小机制**

- 人的环｜换位置（甲方 → 技术负责人）、换关系（工具 → 师徒）、换存法（现场翻书 → 提前编好）、换落点（聊天记录 → Skill），Skill 的产出回流成新上下文。
- 组织的环｜涌现概率 = 环境触发 × 内在可燃性 × 首次成功体验；四层运营识别 → 赋能 → 激励 → 扩散，扩散出的人变成新火种。
- 交易的环｜找卡点 → 可逆切入 → 人终审 → 用数据 → 找站台，赢单变成案例，案例变成下一个客户的开局可信度。

**共同的失败模式**：三个环停下来都是同一个原因——在非瓶颈上发力。个人停在浅用，组织停在培训，业务停在优化非瓶颈环节。

## 关键要点

- **三条线共用一个发动机**——人 / 组织 / 交易三个尺度，同构于 Context not Control
- **三个闭环都是自增强的**——环的产出是下一轮输入，转够时间才有复利
- **主线走人的线**——对外讲从「我怎么变」开场，组织与业务是放大与兑现
- **每个环都有明确的停摆原因**——在非瓶颈上发力
- **一个反直觉结论**——组织不是被培训点燃的，是被晋升/考核这种「不得不」点燃的
